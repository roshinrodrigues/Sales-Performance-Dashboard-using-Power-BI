# Sales-Performance-Dashboard-using-Power-BI# Sales Performance Dashboard using Power BI

## Project Overview
This project focuses on analyzing sales data using Power BI to understand business performance through interactive dashboards.

## Objectives
- Analyze overall sales performance.
- Track revenue and KPIs.
- Identify sales trends and patterns.
- Present insights through visualizations.

## Tools & Technologies
- Power BI
- Power Query
- DAX
- Microsoft Excel

## Key Features
- Interactive sales dashboard
- Sales performance analysis
- KPI visualization
- Trend analysis
- Interactive charts and filters

## Project Files
- Sales_Performance_Dashboard.pbix
- Dataset.xlsx
- Screenshots/

## Outcome
Created an interactive dashboard to visualize sales performance and understand business insights.
